# React Firebase E-Commerce Website

A responsive E-Commerce web application built using React.js and Firebase as part of the CodeAlpha Internship.

## Features

- User Signup & Login
- Firebase Authentication
- Product Listing
- Add to Cart
- Checkout
- Order Management
- Admin Panel
- Firebase Firestore

## Technologies

- React.js
- Firebase Authentication
- Cloud Firestore
- React Router DOM
- CSS
